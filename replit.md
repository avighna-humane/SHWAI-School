# SHWAI

SHWAI is a frontend-only React 19 + TypeScript + Vite demo for an AI-native school operating system.

## Running on Replit

- The `Start application` workflow runs the Vite dev server on port 5000.
- Use the Replit Preview to view the app.
- The local equivalent is `npm run dev -- --host 0.0.0.0 --port 5000`.
- `npm run build` creates a production build.

## Project notes

- Data, authentication, payments, and AI responses are simulated in the browser.
- The app uses TanStack Router/Start, Tailwind CSS v4, shadcn/ui primitives, Recharts, and Framer Motion.
- The application shell, navigation, routes, and mock functionality are preserved while the main content uses the SHWAI visual system.

## User preferences

- Keep the existing React/Vite/TanStack structure intact.
- Preserve the header, footer, sidebar, navigation, routes, and existing interactions when improving page content.
